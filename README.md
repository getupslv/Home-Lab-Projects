## Project 1: Command Line Networking Diagnostics

### Objective: 
To analyze my local home network architecture, test connectivity boundaries, and map internet routing paths using Windows Command Prompt (CMD).

### Steps Performed:
1. **IP Configuration Analysis:** Ran the `ipconfig` command to identify my host PC's IPv4 address and locate the default gateway of my home router.
2. **Connectivity Boundaries:** Utilized the `ping` command to test communication between my workstation and external public servers (8.8.8.8).
3. **Network Routing Trace:** Executed a `tracert` to map the physical hops my data takes traveling across networks out to the broader internet.
